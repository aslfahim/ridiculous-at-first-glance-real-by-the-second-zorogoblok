# Ridiculous at First Glance, Real by the Second — @zorogoblok

One sentence pitching a bizarre startup that sounds absurd until you realise
it would actually sell: professional mourners for hire. Grieving families pay
trained strangers to weep, wail, and eulogize at funerals — because a packed,
tear-soaked send-off honors the dead and spares the family shame.

`main.py` (Python stdlib only) writes that single sentence to `/output/entry.txt`.
